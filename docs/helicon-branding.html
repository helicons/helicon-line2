06 — Do & Don't
Uso Correcto de Marca
✓ Correcto
— Usar negro puro (#050505) como fondo base
— El púrpura solo para acentos y CTAs
— Space Mono para todos los labels y UI
— Clash Display / Georgia solo para titulares
— Mantener el noise-texture sutil (opacity 0.03)
— Imágenes oscuras, cinematográficas, en blanco y negro
✗ Incorrecto
— Fondos blancos o grises claros
— Colores brillantes o neones distintos al púrpura
— Tipografías sans-serif genéricas (Arial, Roboto)
— Logos deformados o con sombras añadidas
— Imágenes de stock genéricas o muy saturadas
— Gradientes de colores que no sean negro→púrpura
